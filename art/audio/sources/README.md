# Sources audio

Enregistrements de tirs : **Gunshot Sounds**, Vincent Sevedge (2009).
Source : https://opengameart.org/content/gunshot-sounds
Archive : https://opengameart.org/sites/default/files/sounds.zip
La page affiche CC0, mais l'archive contient une licence **Creative Commons Attribution 3.0** : nous conservons cette attribution et cette licence, plus restrictive.
Licence : https://creativecommons.org/licenses/by/3.0/
Les fichiers cz.wav, shotty.wav et sks.wav ont été découpés, convertis en mono, filtrés et normalisés par `prepare_recordings.mjs`. Les sons livrés sont `recorded_pistol.wav`, `recorded_shotgun.wav`, `recorded_rifle.wav`.

Pas et impacts : **Impact Sounds**, Kenney (Kenney.nl), **CC0 1.0**.
Source : https://kenney.nl/assets/impact-sounds
Licence : https://creativecommons.org/publicdomain/zero/1.0/
Fichiers livrés : footstep_concrete_000 à 004, footstep_snow_000 à 004, impactMetal_light_000 à 002. Leurs noms sont conservés, sans modification des fichiers. Les sons de neige servent de bruit de semelle dans la poussière lunaire. Les pas intérieurs utilisent uniquement les semelles enregistrées ; la couche d'impact métallique a été retirée.
